# 用語集

| 用語 | 意味 |
| --- | --- |
| Astro | このサイトで使っている静的サイトフレームワーク |
| Content Collections | Astro のコンテンツ管理機能。ブログ記事の schema と読み込みを担う |
| blog collection | `src/content/blog/` に置かれた Markdown 記事群 |
| frontmatter | Markdown ファイル先頭の `---` で囲まれたメタデータ |
| slug | 記事 URL に使われる識別子 |
| pagination | ブログ一覧を複数ページに分ける仕組み |
| layout | 複数ページで共通利用する HTML 構造 |
| component | Astro の再利用 UI 部品 |
| public assets | `public/` に置く画像や favicon などの静的ファイル |
| dist | `npm run build` で生成される本番用ファイル |
| AI Agent | Codex など、このリポジトリで開発支援を行う AI |
