# AI 作業フロー

このドキュメントは、AI Agent がこのリポジトリで作業するときの基本フローを定義します。

## Analyze

- TODO: 依頼内容、影響範囲、既存実装を確認する。

## Search

- TODO: 類似コード、既存パターン、関連ドキュメントを検索する。

## Plan

- TODO: 変更方針、対象ファイル、確認方法を整理する。

## Implement

- TODO: 小さな単位で実装し、既存設計に合わせる。

## Test

- TODO: 実行可能なテスト、ビルド、静的チェックを行う。

## Review

- TODO: 差分をセルフレビューし、不要な変更や重複を確認する。

## Complete

- TODO: 変更内容、確認結果、残課題を報告する。

## 実装前

- 類似コードを探す。
- 重複実装を避ける。
- 必要な依存関係を確認する。

## 実装中

- 小さく変更する。
- 命名規則を遵守する。
- エラー処理を確認する。

## 実装後

- テストを行う。
- セルフレビューを行う。
- 必要に応じてドキュメントを更新する。
