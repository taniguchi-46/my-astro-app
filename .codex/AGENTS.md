# Codex Agent Guide

このファイルは、このリポジトリで Codex が作業するときの行動原則を定義します。

## 基本方針

- まず `docs/` 配下の共通ドキュメントを優先して参照する。
- 作業内容に関係する `.agents/skills/` のファイルだけを参照する。
- 既存コード、既存設計、既存の命名規則を尊重する。
- 大規模変更は避け、必要最小限の変更に分割する。
- 不明点がある場合は、根拠のない推測実装をしない。
- 実装後は可能な範囲でテストを優先して実行する。
- 完了前に差分をセルフレビューする。

## 参照順

1. `README.md`
2. `docs/ai.md`
3. `docs/status.md`
4. `docs/loop.md`
5. 必要な `.agents/skills/*`
6. 必要に応じてその他の `docs/*.md`

## README への参照方法

README にはプロジェクト全体の概要と AI 用ドキュメントの配置を記載します。
Codex 固有の行動原則は `.codex/AGENTS.md` に置き、AI 共通の知識は `docs/` に集約します。

## 作業時の注意

- 既存ファイルを移動した場合は、相対リンクが壊れていないか確認する。
- 不要な削除は行わない。
- TODO が残っていても、構造を優先する作業では許容する。
- 作業完了時は、作成・移動・更新したファイルを報告する。
