# 汎用開発スキル

このメモは、新しいプロジェクトで AI Agent が開発するときに参照する短い作業ルールです。

## 使う場面

- ページ、コンポーネント、API、ドキュメントを追加・修正するとき。
- AI Agent が作業前にプロジェクト固有の前提を確認したいとき。

## 手順

1. `docs/status.md` で現在状況と保留事項を確認する。
2. `docs/architecture.md` で対象領域の構成を確認する。
3. `docs/conventions.md` で命名と実装ルールを確認する。
4. 関連する既存ファイルを探す。
5. 既存パターンに合わせて小さく実装する。
6. 可能なら確認コマンドを実行する。
7. 必要に応じて `docs/status.md` やテンプレートを更新する。

## 注意

- プロジェクト固有 docs と汎用テンプレートを混ぜない。
- 文字化けした文言はそのまま残さない。
